CPI — Cartas de Pronóstico (SMN)

Las Cartas de Pronóstico Interpretadas se descargan directamente desde el sitio oficial del SMN. Por política de CORS del navegador no pueden incrustarse ni scrapearse automáticamente; el botón abre la fuente oficial.

METAR — SMN Descarga de Datos

Portal oficial de estaciones y datos horarios del SMN (no ofrece endpoint JSON público apto para fetch desde el navegador). Podés abrir el portal, o pegar abajo el texto METAR crudo (una línea por estación) para graficarlo sobre el mapa usando la base de estaciones de Grupo TRP.
Se reconocen ~35 estaciones principales de Argentina por código OACI (SAEZ, SABE, SACO, SAME, SAZR, SAAR, SANT, etc.)
